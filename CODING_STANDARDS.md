# Coding standards

These skills are run by strong models and published for anyone to install. Review a change against these judgement calls:

- **A SKILL.md carries only what a strong model cannot know on its own**: the user's intent and preferences, how this skill hands off to others, and lessons learned the hard way. Flag guidance that teaches what the model already does, such as tool order, report formats, or arbitrary counts. Strict rules and long procedures make the output worse, not more reliable.
- **A rule a bundled script enforces lives in the script.** The SKILL.md names the script and what to do with its errors; it does not restate the checks.
- **Judge each rule as if the reader has no global instructions.** A skill cannot rely on its author's own CLAUDE.md or memory.
- **Prefer editing an existing sentence to adding a section.**
