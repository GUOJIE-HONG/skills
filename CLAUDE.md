## Agent skills

### Issue tracker

Issues 放在 GitHub Issues（GUOJIE-HONG/skills），用 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

用預設五個 label：needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目錄一份 `GLOSSARY.md` + `docs/adr/`。See `docs/agents/domain.md`.

### 新增 skill、發版

新增或搬動 skill、寫測試、升版本、發 release 前讀 `docs/agents/adding-a-skill.md`。
